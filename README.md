# لوحة تحكم حمادة للتوصيل

واجهة إدارية ثابتة (HTML + CSS + ملف `app.js` واحد) تعمل في المتصفح مباشرة وتقرأ
Firestore وتكتب فيه بلا أي سيرفر وسيط ولا خطوة بناء ولا حزم npm.

- الموقع الحيّ: <https://hamadatawsil.github.io/tawsil/>
- المستودع: `hamadatawsil/tawsil` — ونشر GitHub Pages يتمّ من مجلد `docs/`.
- مشروع Firebase: `hamada-a449c`.

## الملفات

`docs/` و`public/` نسختان متطابقتان بايت بايت من نفس الملفات. عدّل `docs/` ثم انسخه
إلى `public/` ولا تجعلهما يختلفان، وكلاهما يحمل نفس `?v=` في `index.html` لكسر المخزن
المؤقت عند النشر.

```
docs/  (وpublic/ نسخةٌ منه)
├─ index.html     الواجهة والأقسام
├─ app.js         كل المنطق: الدخول، القراءات، الكتابات، الصلاحيات
├─ style.css      التنسيق العربي RTL
├─ logo.png
└─ ringtone.wav   نغمة الاتصال التي يسمعها صاحب التوصيل داخل التطبيق
```

## الدخول والصلاحيات

- حقل الدخول اسمٌ مستعار يترجمه `AUTH_EMAIL_BY_USERNAME` إلى بريد (مثلًا `admin` →
  `admin@tawsil.app`) ثم يُتحقق به عبر Firebase Auth بالبريد وكلمة المرور.
- بعد الدخول لا عمل بلا وثيقة `admins/{uid}`. الدرجات: **مالك**، **مشرف**، **مطالع**.
- حساب المالك لا يُحذف ولا تُبدَّل درجته: يمنع ذلك الوجهُ في اللوحة وتمنعُها قواعد
  Firestore، ولا يُنشأ مالكٌ ثانٍ.
- طلبات الولوج الذاتية تصل إلى `admin_requests/{uid}` بحالة `pending`، وموافقة مشرفٍ
  قائم وحدها تكتب `admins/{uid}`.

## الأقسام

- **لوحة الإحصائيات**: أرقام اليوم، طلبات قيد المراجعة، أصحاب التوصيل، المكالمات.
- **طلبات التسجيل**: الاسم والهاتف والصور الأربع للمراجعة، مع قبول أو رفض. الطلب الذي
  تصل صوره ناقصة لا يُعرض للبت.
- **أصحاب التوصيل**: بطاقة القرار لكل رقم — اشتراك مدفوع بشهره، أو فترة تجريبية يمنحها
  المشرف، أو تجميد، أو طرد، أو إيقاف. هذه البطاقة هي التي تحدد ظهوره للزبائن: لا قرار
  سارٍ فلا ظهور ولا اتصالات، حتى لو قال هاتفه «متاح». وأزرار إدارة الأرقام والصلاحيات
  والنسخ الاحتياطي للقرار هنا.
- **سجل التواصل**: المكالمات التي تمت داخل التطبيق عبر بروتوكول الندّ للندّ الخاص
  بالتطبيق، مع سبب الإنهاء ورقم الهاتف، وإمكانية قطع مكالمة جارية.
- **المناطق**: الأحياء التي تُعرض في التطبيق. دائرة الكيلومتر الواحد هي التي تحدد
  القرب، وهي حدٌّ هندسي لا قائمة أحياء.
- **سجل النشاط**: كل عملية مكتوبة باسم من قام بها ووقتها.
- **الإعدادات**: ثمن الاشتراك، رقم الدفع وشرحته، وإدارة المشرفين.

## ما حُذف في 2026-10-26

`server.js` و`db.js` و`setup_firestore.js` و`start.bat` ومجلد `data/` (قاعدة SQLite
محلية) عنقودٌ ميت: لا يقرأ منه شيءٌ في الواجهة المنشورة، و`setup_firestore.js` كان
ينشئ مشرفًا بكلمة مرور نصُّها `admin123` في Firestore. حُذف من الشجرة، وهو مرجوع في
تاريخ المستودع السابق لهذا الحذف إن احتاجه أحد.

## نشر قواعد Firestore

القواعد في مستودع التطبيق (`App_Hamada_Tawssil/hamada/firestore.rules`) ولا تُنشر إلا
من ذلك المجلد. النشر بحساب مالك المشروع في صفحة Firebase، لأن حساب أدوات Firebase
المسجّل على هذا الجهاز لا يملك صلاحية النشر في `hamada-a449c`.

قبل نشر قواعد الظهور يجب تشغيل زر «توحيد الصلاحيات» في لوحة أصحاب التوصيل على البيانات
الحيّة، وإلا صار كل صاحب توصيل قائم بلا بطاقة قرار فأُخفي عن الزبائن لحظيًا.
